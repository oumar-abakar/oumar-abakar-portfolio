# Portfolio — Oumar Abakar

Portfolio personnel statique, responsive et sans dépendance d'exécution.

## Lancer le site

```bash
npm run dev
```

Puis ouvrir l'adresse indiquée par Vite.

## Personnalisation rapide

- Remplacer `contact@aliguine.com` dans `index.html`.
- Remplacer les liens `LinkedIn` et `CV` marqués par `data-placeholder`.
- Les blocs visuels abstraits peuvent être remplacés par des images dans `index.html`.
- Modifier les couleurs principales dans les variables en tête de `src/style.css`.

Le site est statique : aucun téléchargement de dépendance ni compilation n'est nécessaire.
